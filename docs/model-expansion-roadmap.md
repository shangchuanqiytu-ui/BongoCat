# 兔兔模型扩展路线图

> 2026-08-21 调研定稿。现状：2D Live2D 兔兔（阿米娅），34 表情 + 19 动作 + 工具调用联动 + 闲时行为系统。
> 目标：扩展模型能力——更多动作、新形象、乃至 3D 化。

## 一、Live2D 模型是怎么做出来的（背景）

一只 Live2D 模型 = 三个职业的接力：**画师**（分层 PSD 立绘，几十上百层）→ **绑定师**（Cubism Editor 里画网格/绑变形器/调参数，市场价几千到几万）→ **动画师**（K 动作）。

编程的编辑器产物是**语言（文本）**，可以 AI 生成；Live2D 编辑器的产物是**视觉手工**（上万次拖网格），这是它难以完全自动化的根源。但 2024-2026 AI 已吃掉大半：

| 环节     | 自动化现状                                                          |
| -------- | ------------------------------------------------------------------- |
| 拆分原画 | 官方 AI 深度学习 PS 插件（半自动）                                  |
| 绑定脸部 | Cubism Editor 5.0 起**一键生成**（部件到位后自动出变形器+角度动作） |
| 物理摇摆 | 一键自动                                                            |
| 身体绑定 | 社区"一键自动绑定身体"工具（B 站教程实证）                          |
| 动画     | motion3.json 纯 JSON，本项目已有生成器全包                          |
| 整体     | B 站已有《AI 全自动生成 Live2D 模型》等实践，"小白一天速通"真实存在 |

**结论：从零做一只 Live2D 模型已从"以月计"降到"周末项目"。**

## 二、扩展路线（按性价比排序）

### 路线 A：向原作者要 .cmo3 源工程（最优先，5 分钟）

手里只有编译后的 .moc3，**没有 .cmo3 源工程**——这是深度扩展（改衣服/新道具/真跑步摆臂）的唯一卡点。
**动作**：B 站/爱发电私信"泡芙妙妙屋"（模型作者）求工程文件，只作个人桌宠使用。

### 路线 B：移植官方示例动作包（半小时见效）

Live2D 官网免费示例模型（Hiyori、Mao 等，`live2d.com/en/learn/sample/`）带成套 motion3.json。
动作文件独立、头/眼/嘴/身体角度等**标准参数跨模型通用**，可直接移植（模型专属参数自动无效）。
**分工**：下载两个包发我 → 我写参数映射脚本批量移植 → 验收接入。

### 路线 C：明日方舟官方提取（❌ 已调研，不可行）

官方动态立绘大量是 Spine/私有格式，非标准 Cubism Live2D，装不进现有管线。放弃。

### 路线 D：AI + 自己做（周末项目）

1. 装 Cubism Editor 5（免费版够用）+ 官方 AI 拆分 PS 插件
2. AI 生成立绘 → AI 拆层 → 一键绑脸 → 一键物理 → 社区工具绑身体
3. 动画/物理调参/接入桌宠系统全由本项目侧包办
4. 参考官方示例的公开 .cmo3 源工程练手（比从零画快十倍）

## 三、3D 化路线（画风换挡：VRM 动漫风）

若接受 3D 画风（VRoid/VRChat 风），AI 自动化比 Live2D 更彻底（~90%）：

```
一张图 → 在线图生 3D → Mixamo 自动绑骨+动作库 → 转 VRM → three-vrm 桌宠壳
```

| 步骤     | 工具                                                | 费用      |
| -------- | --------------------------------------------------- | --------- |
| 图生 3D  | **腾讯混元 3D**（3d.hunyuan.tencent.com，国内直连） | **免费**  |
| （备选） | Tripo（每月送积分）/ Meshy（额度有限易收费）        | 免费/收费 |
| 自动绑骨 | Mixamo（Adobe 网页）                                | 免费      |
| 桌宠壳   | Tauri + three-vrm，现有对话/记忆/闲时系统可整体迁移 | 我来      |

**本机兜底**：本地 TripoSR（CPU 推理，Ultra 7 155H 一张图几分钟，质量中等，完全免费无限量）。
**注意**：本机 4GB 显存跑不动主流图生 3D 模型（要 8GB+），在线版为主。
